# SQLD 공학노트

SQLD(SQL 개발자) 시험 대비용 단일 페이지 학습 앱입니다. 55~61회 복원 기출의 출제 경향을 분석해 만들었습니다.
설치 없이 `index.html`을 열면 되고, GitHub Pages를 켜면 `https://yellow8227-cmd.github.io/sqld/`에서 열립니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 개념정리 | 1과목 7개, 2과목 17개 주제의 핵심 표·공식·암기 고리, 주제별 출제 추이 막대 |
| 암기카드 | 72장, 주제 필터, 외운 카드 숨기기 |
| 문제풀이 | 81문항(1과목 16 · 2과목 65), 과목·주제·순서 필터, 단계별 추적 해설 |
| 오답노트 | 틀린 문제가 자동으로 쌓이고, 맞히면 빠짐 |
| 모의고사 | 실전 구성 50문항(1과목 10 + 2과목 40), 90분 타이머, 과락 판정, 주제별 정답률 |
| 출제분석 | 55~61회 주제별 출제 히트맵, 다음 시험 우선순위 |

해설은 모든 문항에서 같은 순서로 나옵니다. **정답 → 핵심 원리 → 단계별 추적 표(원본 → WHERE 필터 → 연산 → 최종 결과) → 보기별 분석 → 출제 함정 → 암기 고리**.
약어는 문항마다 처음 나올 때 괄호로 풀어 씁니다. 예: DDL(Data Definition Language, 데이터 정의어)

## 정답 검증

`tools/verify.mjs`는 각 문항의 제시 표를 PostgreSQL 테이블로 그대로 만듭니다. 그다음 같은 의미의 쿼리를 실행해, 화면의 '최종 결과' 표와 한 칸씩 대조합니다.
현재 계산형 47문항이 통과했습니다. 나머지 34문항은 이론 문항이거나 Oracle에서만 그렇게 동작하는 문항입니다(DDL 자동 커밋, `'' = NULL`, DECODE 등). 이 문항들은 해설에 근거를 적었고, 따로 검토했습니다.

```bash
createdb sqld
node tools/verify.mjs
```

## 파일

```
index.html        화면·스타일
app.js            화면 로직 (학습 기록은 브라우저 localStorage)
data/q1.js        1과목 문항
data/q2~q4.js     2과목 문항
data/concepts.js  주제 목록·개념정리·암기카드·출제 추이
tools/verify.mjs  정답 검증기
tools/trend-raw.json  출제 추이 원자료(키워드 분류 결과)
```

## 출처와 한계

출제 추이는 수험생이 공개한 복원 문항을 키워드 규칙으로 자동 분류한 근사치입니다. 한국데이터산업진흥원의 공식 자료가 아닙니다.
문항은 출제 유형만 참고했고, 지문·데이터·보기는 모두 새로 만들었습니다.
