# SQLD 공학노트

SQLD(SQL 개발자) 시험 대비용 학습 앱입니다. 공식 출제기준의 세부항목마다 문제를 두고, 수험생이 자주 틀리는 '고오답 유형'에 무게를 실었습니다.
설치 없이 `index.html`을 열면 되고, 사이트 주소는 https://yellow8227-cmd.github.io/sqld/ 입니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 개념정리 | 1과목 7개, 2과목 17개 주제의 핵심 표·공식·암기 고리, 주제별 출제 추이 막대, 바로 풀기 버튼 |
| 암기카드 | 72장, 주제 필터, 외운 카드 숨기기 |
| 문제풀이 | **250문항**(1과목 50 · 2과목 200). 기본 순서는 **추천(내 기록 기반)**. 과목 → 공식 세부항목 필터, '고오답 유형만' 토글. 문제마다 나온 이유를 표시 |
| 오답노트 | 틀린 문제가 자동으로 쌓이고 맞히면 빠짐. 내 기록으로 계산한 세부항목별 '내 약점' 막대 |
| 모의고사 | **모의고사 1~5회**(회차끼리 문항이 겹치지 않음) + 내 기록 기반 **맞춤 모의고사**. 공식 구성(1과목 10 + 2과목 40, 90분, 문항당 2점), 과락 판정, 세부항목별 결과 |
| 출제분석 | 공식 시험 구성·합격 기준, 2019~2025 연도별 공식 응시·합격 통계, 세부항목별 문항 수, 참고용 복원 기출 추이 |

모든 문항의 해설은 같은 순서로 나옵니다. **정답 → 핵심 원리 → 단계별 추적 표 → 최종 결과 → 보기별 분석 → 출제 함정 → 암기 고리**.
약어는 문항마다 처음 나올 때 괄호로 풀어 씁니다. 예: DDL(Data Definition Language, 데이터 정의어)

## 문제를 고르는 방식 (추천)

무작위가 아니라 내 풀이 기록을 보고 고른다. 문제 위에 왜 이 문제가 나왔는지 표시한다.

| 표시 | 언제 나오나 |
| --- | --- |
| 오답 복습 | 지난번에 틀린 문제. 다음 날 다시 나오고, 같은 공부 중에도 4문제 뒤에 한 번 더 나온다 |
| 간격 복습 | 맞혔던 문제. 3 → 7 → 14 → 30일 간격으로 다시 나온다 |
| 새로 추가된 문제 | 지난 방문 뒤에 문제은행에 들어온 문항 (처음 풀 때까지) |
| 약점 보강 | 정답률 60% 미만인 세부항목의 안 푼 문제 |
| 처음 푸는 고오답 유형 / 처음 푸는 문제 | 그 밖의 안 푼 문제 |

순서는 밀린 오답 3개를 먼저 낸 뒤 '새 문제 2개 : 오답 1개 : 간격 복습 1개'를 돌아가며 섞는다. 새 문제끼리는 세부항목 정답률이 낮을수록, 고오답 유형일수록, 자주 출제되는 주제일수록 먼저 나온다. 오답노트의 문제는 연속 두 번 맞히면 빠진다.

**찍어서 맞힌 문제:** 맞힌 뒤 나오는 '찍어서 맞았어요' 버튼을 누르면 오답노트에 들어가고 다음 날 다시 나온다(다시 누르면 취소). 모의고사에서는 풀면서 '찍음 표시'를 해 두면, 제출할 때 맞힌 문제도 오답노트로 간다.

## 로그인 (기기 간 기록 이어 하기)

아이디·비밀번호만으로 가입하며, 기록은 문제를 풀 때마다 3초 뒤 자동 저장됩니다. 서버는 상식 앱과 같은 Supabase 프로젝트를 씁니다. 다만 표와 함수는 `sq_`로 따로 두어 두 앱의 계정·기록이 섞이지 않습니다.
처음 한 번, Supabase SQL Editor에서 `sqld-setup.sql`을 실행해야 합니다. 여러 번 실행해도 안전합니다.

## 정답 검증

- `tools/verify.mjs`는 각 문항의 제시 표를 PostgreSQL 테이블로 그대로 만들고, 같은 의미의 쿼리를 실행해 화면의 '최종 결과'와 한 칸씩 대조합니다. 현재 **173문항이 이 검증을 통과**했습니다.
- 같은 스크립트가 모든 문항의 구조(보기 4개, 정답 범위, 공식 세부항목 이름)도 확인합니다.
- 나머지 77문항은 이론 문항이거나 Oracle에서만 그렇게 동작하는 문항입니다(DDL 자동 커밋, `'' = NULL`, ROWNUM 등). 이 문항들은 해설에 근거를 적었고, 문항을 쓴 사람과 다른 검토자가 Oracle 기준으로 다시 확인했습니다.

```bash
createdb sqld
node tools/verify.mjs        # 전체 검증
node tools/build-sets.mjs    # 모의고사 세트 다시 만들기 (data/sets.js)
```

## 파일

```

sqld-setup.sql      로그인 서버 설정 (Supabase SQL Editor에서 실행)
data/syllabus.js    공식 출제기준(과목 → 주요항목 → 세부항목)과 문항 매핑
data/q1~q10.js      문항
data/sets.js        고정 모의고사 세트 (build-sets.mjs가 생성)
data/concepts.js    주제 목록·개념정리·암기카드·출제 추이·공식 통계
tools/              검증기, 세트 생성기, 공식 자료 원본(official/), 복원 기출 분류 결과
```

## 출처와 한계

- **공식 자료**
  - **출처:** 데이터자격검정(dataq.or.kr) SQL 개발자 출제기준, 한국데이터산업진흥원 공공데이터 「데이터 자격 검정 상세정보」, 민간자격정보서비스(pqi.or.kr) 자격취득현황입니다. 원본은 `tools/official/`에 있습니다.
  - **앱에 쓴 항목:** 과목·세부항목, 문항 수·배점, 합격 기준(총점 60점, 과목별 40% 미만 과락), 2019~2025 연도별 접수·응시·취득·합격률입니다.
- **공식 자료가 없는 부분:** 시행 기관은 기출문제와 문항·주제별 통계, 문항별 오답률을 공개하지 않습니다.
  - 주제별 출제 추이는 수험생이 공개한 55~61회 복원 문항을 분류한 참고 자료입니다.
  - '고오답 유형' 표시는 수험서·복원 해설에서 반복적으로 함정으로 꼽히는 유형을 기준으로 했습니다.
- **문항 작성:** 출제 유형만 참고했고, 지문·데이터·보기는 모두 새로 만들었습니다.
